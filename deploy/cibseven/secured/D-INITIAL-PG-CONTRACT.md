# Initial PostgreSQL helper and management contract v1

ADR-0057 is the bounded initial allocation. This document and `initial_pg_contracts.py` are inert contracts, not a SQL installer, observer, signer, connection broker or authority. Closed parsed records are untrusted descriptions until the separately implemented owner components independently acquire and authenticate their facts. No public caller, JSON digest or test vector can instantiate live admission.

## 1. Immutable boundary

Original D SQL SHA256 `c857042bd26626dbd14f4e7c6b82280ddcafd156183f3ddb56f18fba1b210606`; original d7-control-0001.json SHA256 `fcf569db7344f677ef543fc892d0b1665ee34aa245471bf92535da2626b4f7a1`. D has seven tables and the complete manifest of57 functions, including internals. Native-v2 separately has6/19. None of these files, original functions, signed DatabaseObservation fields, general/recovery closure or current grants are modified by this slice.

All wire records are canonical D JSON: closed fields, bounded safe integers, no duplicates/floats/unknowns, canonical bytes, <=1MiB. Protocol prefix is `maezo.d7-initial-pg.`; all identities use existing D Scope/UUID/OID/Id/Sha256 grammar. Phase is exactly INSTALLED, RECONCILED or CLOSED, corresponding to F revisions1/2/3. Epoch1, next generation1 and absence of G remain initial-only prerequisites. No PREPARED/OPEN/runtime or restore variant exists.

## 3. Read ABI, committed rows and no F side mutation

`ReadRequest`: protocol, installation_id, control_scope_id, scope, owner_subject, run_id, epoch, phase, expected_fence_revision, reconcile, close. Each nonnull selector is exactly issuer_operation_id/request_sha256. INSTALLED/F1 has both null; RECONCILED/F2 has reconcile only; CLOSED/F3 has both distinct IDs. All fields match actual initial owner/F. No arbitrary operation or foreign receipt selector is supported.

The future fixed read function authenticates real SESSION_USER/OID as observer and CURRENT_USER/OID as D owner; checks exact current database/incarnation/namespace/installation/source/catalog, epoch1/highwater1/no generations and phase's actual F state. It selects the one exact installation row, F row and matching committed reconcile/close rows by actual scope/run/operation ID/request hash. Bound request bytes/result bytes, operation, issuer OID/name/definer, result digests, F revision, null generation/permit and recorded-before-commit timestamp must agree with the unchanged D receipt grammar. No absent/duplicate/partial row yields a successful response.

Successful `ReadResult`: protocol, request_sha256, installation_id, control_scope_id, scope, owner_subject, run_id, epoch, phase, fence_revision, next_generation_id, current_generation_id, restore_state, mode, observed_at_ms, observer_login_oid, definer_oid, backend_pid, backend_start_unix_us, installation_binding_bytes, schema_version_bytes, fence_bytes, reconcile_receipt_bytes, close_receipt_bytes. Embedded bytes are canonical base64url of existing full canonical records; limits include total enclosing1MiB. INSTALLED is UNRECONCILED/CLOSED; RECONCILED is RECONCILED/RECOVERY_REQUIRED; CLOSED is RECONCILED/CLOSED. Runtime generation is null and next generation1. The actual consumer validates all embedded field equality against existing source parsers/installation, not just these projections. Pure contract parsing cannot independently prove commit or stored custody.

Observe on a separate actual READ COMMITTED observer connection after issuer commit. MVCC excludes other transactions' uncommitted receipts. Never create a read permit, call read_issuer_operation, mutate F, use the issuer's own uncommitted cursor or invent an exact commit time. A lost mutation result stays UNKNOWN; this fixed read may recover the exact committed row, while absence stays unknown and cannot cause a new-ID retry. The independent observer composes these actual bytes with census below; stats owner never reads these tables or calls this helper.

## 4. Census ABI and actual field projection

`CensusRequest`: protocol, installation_id, control_scope_id, scope, run_id, epoch, phase, challenge. It contains no supplied D row, receipt/hash or CURRENT_USER claim. Stats helper checks only independently installed exact scope/identity/source; the real observer separately authenticates ReadResult through its own B call, then binds both results to one live phase/challenge/deadline. Request metadata is not that authentication.

The future fixed census result contains bounded arrays from these actual queries; this source slice defines projection records rather than executing queries:

- pg_stat_activity joined current database/roles: PID, exact backend_start, database OID, login OID, state, xact_start, backend_type and route/address identities. Other-backend current_role_oid is **not** a pg_stat_activity field. Preserve raw null/unknown source fields privately; hidden required facts refuse. No query text, password or ACT content is returned.
- pg_prepared_xacts: exact database/owner OIDs, hashed transaction GID, prepared timestamp. Preserve full raw census and explicit scope classification; any scoped prepared transaction refuses, foreign entries are never rolled back.
- pg_roles, complete pg_auth_members ADMIN/INHERIT/SET/grantor, pg_namespace/class/proc/attribute/default ACLs and effective PUBLIC/owner/SECURITY DEFINER paths; no role/password field invention. Exact source definitions and default grant routes are independently pinned.
- current server/version/database, relevant visible settings, fresh clock, max_prepared_transactions, track_activities, SSL. Clear statistics snapshot before actual census. SQL-invisible HBA/network/credential/UID facts come from actual protected host observation, not this helper.

All bounds apply to full observed sets; pagination/truncation/missing visibility is refusal, not empty arrays. Only core PG16 maintenance background activity that is explicitly enumerated in the independently installed profile may be classified; no connected extension/replication/unknown process exception. Authoring this contract does not admit a maintenance profile without actual evidence.

## 5. Connection-owner handoff, barrier and total partition

`ManagementProjection` binds protocol, installation_id/control_scope_id/Scope/run/epoch/phase, read_request_sha256/read_result_sha256/census_request_sha256/raw_database_observation_sha256, barrier, connections and partition. It is an evidence description only, never a sealed admission object. The actual producer must retain complete source bytes, installed membership/ACL/query definitions, actual READ COMMITTED results, original signed control+database observation and independent protected-channel contributions.

Barrier is exactly instance_id, generation, supervisor_pid, supervisor_start_unix_us, supervisor_uid, network_namespace_inode, source_sha256, host_observation_sha256, opened_at_ms, deadline_ms. Instance is unique per actual started supervisor; generation is1 for this nonrestartable lane. Deadline is strictly later than opened_at and <=opened_at+5000; later source deadlines/lease/credentials may shorten it, never extend it. It is not proof of actual enforcement; source must own and inspect live namespace/HBA/credentials/processes and monotonic deadline before effect.

Exactly two connection contributions, sorted by purpose: DB_OBSERVER then ISSUER. Each has purpose, process_pid/process_start_unix_us/process_uid, source_sha256, channel_nonce, connection_id, backend_pid/backend_start_unix_us, database_oid, login_oid, current_role_oid, state, identity_origin. Processes and backend identities/connection IDs/channels are distinct; no shared observer/issuer UID or credential. Observer self-census state ACTIVE has current_role_oid equal to actual stats function owner inside its fixed function, identity_origin=IN_FUNCTION. Issuer state IDLE has current_role_oid=login_oid from its fixed own-connection query outside definer, identity_origin=QUIESCENT_HANDOFF. SESSION_USER remains the corresponding real login. Supervisor authenticates actual child/channel/source and owns exclusive command dispatch; supplied fields are insufficient.

The dedicated initial host profile has actual PG16 namespace, no other tenant, certificate-only hostssl+exact pg_ident issuer/observer identities, no local socket/password/IAM/proxy route and reject-all remainder. Setup owner credentials/session are closed before sealed interval. Actual installed source/credential gateway supplies separate process UIDs and private anonymous-pipe handles; requester cannot edit source, inspect another UID's credentials or send generic SQL. Original LOGIN attributes remain intact. Credential leak, unknown HBA/network/role route, FD leakage, unexpected process, child death or stale/PID-reused identity refuses and contains future effects; no restart/reissue. A mutex, hash or connection_limit alone is insufficient.

Partition entries are exactly kind, identity, classification, purpose. kind=SESSION identity is exact backend_pid/backend_start_unix_us; kind=ROUTE identity is route_id. classification=CLOSED has purpose null; QUALIFIED_MANAGEMENT has DB_OBSERVER or ISSUER. Retain every original signed raw session/route and exactly one matching classification; no raw input is dropped or modified, no prepared exception. A structural `check_projection` takes the actual retained raw DatabasePayload to enforce total coverage and exact connection/role/state/binding relationships; it still cannot establish signature, host or source authority. Generic recovery keeps rejecting the same management rows.

Live supervisor phases remain install/seal/handoff/census → exact reconcile → fresh handoff/census/read F2 → exact close → fresh handoff/census/read F3 → ROOT CAS → first reservation. During issuer effects do not sign a new observation falsely representing it idle; acquire a new actual handoff afterward. Control observer is distinct in key/purpose/source; exact actual cloud issuance and parent interval are separately owned and unapproved here. Proposed cloud handoff must match installation/control scope/Scope/run/epoch, actual child/source/credential expiration and barrier lifetime; no continuation privilege is inferred from L1 v1.

## 6. Negative controls and remaining implementation

Inert tests must refuse unknown/missing fields, noncanonical/oversized records, phase/F/receipt mismatch, foreign scope, shared identities, unproved other-backend effective role, invalid issuer/observer state, loose membership options, extra helper/ACL principal, hidden projection row, missing/duplicate partition, prepared transaction, expired/extended barrier and wrong original D pins. Existing D/native source hashes/counts are independently checked and never rewritten to satisfy tests.

Effect implementation remains absent: exact SQL bodies with source pins, initial installer, readback/census actual transport, signature acquisition, host supervisor enforcement, concrete IssuerAuthority/StageQualification, original-creation cloud writer and actual F/ROOT/reservation orchestration. Each needs independent source/runtime gates. Real PG must demonstrate initial catalog compatibility, non-mutating independent committed readback F1→2→3, actual definer/self/issuer census, private credential/host seal and meaningful foreign/hidden/expiry controls. No full native/Q2/L3/V11, merge or production acceptance follows.

## 7. Implemented inert record closure

This bounded module accepts only `manifest`, `read-request`, `census-request` and `management-projection` (protocol suffix `.v1`). ReadResult and census-result are not accepted kinds: their future producer must first define and validate the complete existing row grammar. No opaque row bytes are accepted as a qualified result by this slice.

Manifest exact fields: protocol, installation_id, control_scope_id, scope, original_sql_sha256, original_manifest_sha256, d_table_count, d_function_count, roles, statistics_membership, helpers, external_acl_sha256, host_profile_sha256, supervisor_source_sha256, observer_source_sha256, issuer_source_sha256, routes. Roles exact D_OWNER, STATS_OWNER, DB_OBSERVER, ISSUER, each exact name/oid and mutually distinct. Original D owner/observer/issuer come from independently authenticated original installation, not generated names. Statistics membership exact member_oid/role_oid/grantor_oid/admin_option/inherit_option/set_option; member is STATS_OWNER, role is independently resolved pg_read_all_stats, distinct from these roles; options false/true/false. Grantor is independently read actual OID, never inferred.

Helpers ordered READBACK, STATS. Each exact purpose/namespace/namespace_oid/function/function_oid/owner_oid/definition_sha256/security_definer/volatility/parallel/search_path/namespace_usage_oids/execute_oids. Exact namespaces and functions are from section2; owner follows purpose, security_definer=true, volatility=VOLATILE, parallel=UNSAFE, search_path=[pg_catalog,pg_temp]. The only explicit caller grant is observer OID in each of the two ACL arrays; implicit owner authority is checked separately in complete ACL evidence. OIDs are distinct within their own catalog, namespace names cannot shadow D or ACT. Route allocations are exact route_id/purpose/kind/frontend_identity_sha256/network_binding_sha256/qualified_adapter_sha256, sorted unique route_id; purpose DB_OBSERVER or ISSUER, kind CERTIFICATE or SECURITY_DEFINER. These are source-pinned intended routes, not a caller-created allowlist. Actual complete ACL/HBA/host evidence must justify every allocated route before any live consumer exists.

`check_projection` requires separately parsed manifest/read/census and full original DatabaseObservation wire bytes. It re-parses the original schema, preserves all bytes, and binds every scope/run/epoch/F/hash. It checks current database, actual observer names, owner/login attributes, exact stats membership, self-census role and issuer identity against the manifest. Both live sessions must be QUALIFIED_MANAGEMENT; a session cannot be CLOSED merely because its state is idle. No additional session/prepared transaction/generation is allowed. Every raw route is partitioned exactly once; CLOSED requires disabled and zero in-flight, qualified routes require exact installed manifest route/purpose/kind/identities, only that connection's login, no generation, and zero in-flight. All allocated routes must appear. This rejects missing/duplicate/extra rows without dropping raw evidence. Bounds are <=1024 routes/partition entries; excess refuses.

Barrier parsing checks the fixed <=5000ms interval; structural checking also requires an explicit `now_ms` in that interval and original signed observation issuance/expiry within it. It binds raw observation admission-barrier digest to canonical barrier bytes. This is still only structural consistency: no signature is verified and `now_ms` is not an authenticated clock. The implementation returns no authority object and has no runtime callers. A real consumer must independently acquire/authenticate all inputs, complete ReadResult and statistics/host evidence and enforce remaining source/ACL/current-policy facts before using any projection.
