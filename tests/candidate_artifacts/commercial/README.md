# Artefato candidato imutável para testes

Estes bytes pertencem exclusivamente à proposta AMH no commit/path/hash de PROVENANCE.json. Não editar nem derivar outro contrato aqui: mudanças vêm da AMH e exigem nova importação e revisão. Este namespace é separado dos fixtures publicados e do contracts.lock.json. O artefato não publica contrato, não qualifica fonte e não é carregado pelo runtime. Os testes falham se os bytes ou a proveniência não corresponderem ao fingerprint esperado.
